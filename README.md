<b>UFCgram 🤳</b> <br> <br>
O UFCGram é uma rede social voltada aos estudantes da Universidade Federal do Ceará
(UFC), na qual os usuários podem criar perfis, se conectar com outros
membros, compartilhar conteúdos e interagir com as publicações da comunidade acadêmica.

## ℹ️ Sobre o Projeto
UFCgram é um programa em Java com o paradigma da Programação Orientada a Objetos (POO), usando com interface gráfica junto com uma conexão com o Banco de Dados 
<ul>
  <li>Linguagens: Java, FXML e CSS;</li>
  <li>Bibliotecas: JavaFX, AtlantaFX;</li>
  <li>Banco de Dados: Postgree.</li>
</ul>
